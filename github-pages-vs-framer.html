GitHub Pages 和 Framer，该怎么选？

一个完全免费但需要一点代码，一个视觉精致但需每月付费。从成本、代码要求、上线速度、长期成长性等 9 个维度帮你判断。

真实场景：小陈是计算机系大三学生，他用 GitHub Pages 免费搭建了一个技术博客，记录刷题笔记和项目复盘，一年后这个博客帮他拿到了大厂实习内推。而周总是一位 SaaS 创始人，他的产品即将上线，需要一个能传递品牌信任感的官网。他用 Framer 做了一周，网站上线当天就有投资人主动发邮件约见面。一个是零成本验证，一个是品牌投资，选择取决于你处在哪个阶段。

一句话总结：预算为零选 GitHub Pages，追求设计感选 Framer。两者不是竞争关系，而是不同阶段的工具。

先说结论

GitHub Pages 适合预算为零的人，Framer 适合追求设计感的人。

想省钱选 GitHub Pages，想省时间选 Framer。

新手建议先明确目标再选，不确定就看编辑建议。

5 分钟对比表

对比维度 GitHub Pages Framer
上手难度 GitHub Pages 需懂 HTML/CSS 和 Git Framer 需理解设计系统，有学习曲线
页面美观度 GitHub Pages 取决于你的前端能力 Framer 设计师级别，视觉效果顶尖
SEO GitHub Pages 静态页面加载快，搜索引擎友好 Framer 基础支持，不如专业 CMS 完善
成本 GitHub Pages 完全免费 Framer 免费版可用，高级功能约 $15-25/月
适合谁 GitHub Pages 开发者、预算为零的创业者 Framer 设计师、需要网站是竞争力的人

我的建议

选 GitHub Pages 如果你：预算为零、愿意学一点技术、想先验证想法再决定是否投入。

选 Framer 如果你：需要网站本身就是说服力的一部分、不想碰代码、愿意每月付费换效率。

折中方案：先用 GitHub Pages 做 MVP 验证，验证成功后再迁移到 Framer 或 WordPress。
